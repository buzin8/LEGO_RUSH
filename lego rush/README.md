# LEGO Rush

A browser based 3D endless runner. Open `index.html` through a local web server or deploy this repository as a static site on Vercel.

## Run locally

From this directory, run:

```powershell
python -m http.server 8000
```

Then open <http://localhost:8000>.

The game uses Three.js, Tailwind CSS, and fonts from CDNs, so those visuals need an internet connection.

## Controls

- A / D or Left / Right: change lanes
- W / Space / Up: jump; Space near a train can board the roof
- P / Esc: pause
